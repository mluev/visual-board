Whiteboard and Explainer

Whiteboard is a freehand canvas for sketching, working through math or labeling a diagram, and it saves with a boardId. Explainer is the text block that introduces a concept, with optional code and key points.

Whiteboard: title · prompt · height · boardId — Explainer: label · title · body · code · points[]
